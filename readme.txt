This repository stores a small Task List app built entirely from Python. The Task List app allows users to enter a list of things they have to do. Through the use of a while loop,
the same input runs repeatedly and appends all inputs into the list. Once the user has finished adding all of their tasks, the loop finishes and a confirmation message is printed on the terminal.
In addition to that, the app also prints out a statement that tells the user how many tasks, in total, they have to do.

In terms of challenges, I faced some challenges about how to generate a pull request and how to merge the branches together.
